Configure your mouse from the browser

MouseFlash talks to Glorious and other SinoWealth mice over WebHID. Remap the buttons, set DPI stages, record macros, and change lighting. Settings are written to the mouse itself, so they follow it to any computer.

This browser has no WebHID support. Use Chrome, Edge, Opera, or another Chromium browser on desktop. Firefox and Safari cannot do this.

Pick your mouse in the browser prompt. If more than one entry appears for it, any of them will do: MouseFlash filters for the configuration interface.

    Read this before you save anything

    Saving writes to the mouse's onboard flash. This is the same thing the vendor software does, but MouseFlash is not vendor software and the protocol was worked out by reverse engineering. Something unexpected could leave the mouse in a bad state. The buttons and DPI are the well understood parts; lighting and lift-off distance are less so.

    MouseFlash only changes bytes it understands and writes everything else back exactly as the mouse reported it. Export a backup from the Settings tab first.

    DPI stages

    The DPI button cycles through the enabled stages. The selected stage is the one the mouse uses now. Steps of 100 are all the sensor accepts.

    The mouse stores settings for every effect separately, so switching effects keeps the colours you picked for each one.

    Assign a slot to a button on the Buttons tab, then write the slot here. Macros cannot be read back off the mouse, so MouseFlash keeps its own copy in this browser to let you edit them later.

    Recording captures key presses and releases with their real timing. Mouse clicks are added with the buttons below, since clicking the page would record itself.

    Click and tracking

    How long the mouse ignores a switch after it changes state. Lower feels faster but a worn switch may register double clicks.
    How far you can lift the mouse before it stops tracking.

    This mouse handles lift-off distance through a separate command that MouseFlash does not implement, so the control is disabled. Writing to the byte anyway is known to misbehave.

    Backup

    Export writes a JSON file with the raw reports exactly as the mouse gave them, plus the decoded settings. Import restores it.
