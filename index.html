Configure your mouse from the browser

MouseFlash speaks to Glorious and other SinoWealth mice over WebHID. Remap buttons, set DPI stages, record macros, change lighting. Everything is written to the mouse itself, so it follows the mouse to any computer.

This browser has no WebHID. Use Chrome, Edge, Brave, Opera or another Chromium browser on desktop. Firefox and Safari cannot do this.

Pick the mouse in the browser prompt. If it lists more than one entry for the same mouse, any will do.

Supported

    Before you apply

    Applying writes to the mouse's onboard flash, the same thing the vendor software does. The protocol was reverse engineered, not published, so export a backup from the Device panel first.

    MouseFlash only changes bytes it understands and writes the rest back exactly as the mouse reported them.

    Buttons

    Profile

    Not a recognised model. The protocol matches, but the artwork and button count are a generic guess. Export a backup before applying.

    Button
    DPI

    The DPI button cycles the enabled stages. The selected stage is the one in use now. Steps of 100 are all the sensor takes.

    Lighting

    Each effect keeps its own colours, so switching effects loses nothing.

    Performance

    How long a switch is ignored after it changes state. Lower feels faster, but a worn switch starts double clicking.

    This mouse drives lift-off through a separate command MouseFlash does not implement, so the control is disabled. Writing the byte anyway misbehaves.

    Device

    Macro editor

    Assign a slot to a button in the Button panel, then write the slot here. Macros cannot be read back off the mouse, so MouseFlash keeps its own copy in this browser.

    Recording captures key presses and releases with their real timing. Clicks and single keys are added below, since clicking the page would record itself. Drag any row by its handle to reorder.
